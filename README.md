# Olive Hues 🌿

**Olive Hues** is a curated aesthetic discovery tool designed to help you transform your digital or physical space with perfectly paired color palettes and typography. Whether you're looking for the quiet comfort of a library or the vibrant energy of a neon city, Olive Hues provides the inspiration you need.

## ✨ Features

- **Curated Moods**: Choose from several pre-defined aesthetics:
  - **Minimal**: Clean, functional, and simple.
  - **Dark Academia**: Scholarly, moody, and timeless.
  - **Cottagecore**: Whimsical, nature-inspired, and cozy.
  - **Bold & Bright**: Energetic, high-contrast, and vibrant.
  - **Cozy**: Warm, soft, and inviting.
  - **Cyber/Tech**: 
- **Font Pairings**: Each mood comes with professional typography suggestions from Google Fonts to match the vibe.
- **Color Palettes**: Explore multiple 5-color palettes for each mood, complete with hex codes for easy use.
- **Saved Palettes**: Save your favorite palettes to your personal basket for quick access.
- **Custom Themes**: Create and save your own unique aesthetics using the built-in theme designer.
- **Glassmorphism UI**: A modern, sleek interface with animated backgrounds and responsive design.

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3 (Custom properties, Glassmorphism, Animations)
- **Logic**: Vanilla JavaScript
- **Database**: [Supabase](https://supabase.com/) (used for storing saved and custom themes)
- **Typography**: [Google Fonts](https://fonts.google.com/)

## 📂 Project Structure

```text
Olive-Hues/
├── index.html        # Main landing page & mood explorer
├── custom.html       # Custom theme creation page
├── style.css         # Global styles and animations
├── script.js         # Core logic and curated mood data
├── custom.js         # Supabase integration & custom theme logic
└── images/           # Mood preview thumbnails
```

## 🛠️ Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/muskan-fageria/Olive-Hues.git
   ```
2. **Open the project**:
   Simply open `index.html` in your favorite web browser.

3. **Supabase Setup (Optional)**:
   If you wish to use the custom theme saving feature, ensure you have a Supabase project set up and update the credentials in `custom.js`.

## 🎨 Usage

1. Select a mood from the header to instantly transform the page's atmosphere.
2. Browse through the generated palettes.
3. Click the "Basket" icon to view your saved palettes.
4. Navigate to "Custom Themes" to build your own palette from scratch.
